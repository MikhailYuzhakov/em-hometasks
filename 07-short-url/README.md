# Сервис сокращения ссылок

Этот сервис позволяет сокращать длинные URL-адреса, создавать пользовательские (читаемые) псевдонимы для коротких ссылок и устанавливать срок действия для временных ссылок. По истечении срока действия ссылки автоматически удаляются.

## Технологии

*   Java 17
*   Spring Boot 3.x
*   Spring Data JPA
*   PostgreSQL
*   Flyway для миграций базы данных
*   Lombok для сокращения шаблонного кода
*   Testcontainers для интеграционных тестов
*   Maven для управления проектом

## Особенности

*   **Сокращение URL**: Преобразование длинных URL в короткие.
*   **Пользовательские псевдонимы (Alias)**: Возможность задавать свои, легко читаемые псевдонимы для коротких ссылок. Если псевдоним не предоставлен, он генерируется автоматически.
*   **Срок действия (TTL)**: Возможность устанавливать срок действия для коротких ссылок. Просроченные ссылки автоматически удаляются фоновой задачей.
*   **Валидация**: Встроенная валидация входных данных для URL и псевдонимов.
*   **Глобальная обработка исключений**: Единый формат ответов для различных ошибок API.
*   **Интеграционные тесты**: Использование Testcontainers для проверки взаимодействия с реальной базой данных.

## Запуск приложения

### 1. С помощью Docker Compose (рекомендуется для разработки)

Убедитесь, что у вас установлен Docker и Docker Compose.

1.  **Сборка приложения:**
    ```bash
    ./mvnw clean package -DskipTests
    ```

2.  **Запуск сервиса и базы данных:**
    ```bash
    docker-compose up --build
    ```

Приложение будет доступно по адресу `http://localhost:8081`.
База данных PostgreSQL будет доступна на порту `5432`.

### 2. Вручную (требуется установленный PostgreSQL)

1.  **Настройте PostgreSQL:**
    Создайте базу данных `short-url` и пользователя `postgres` с паролем `postgres` (или обновите `src/main/resources/application.yaml` соответствующим образом).

2.  **Сборка и запуск приложения:**
    ```bash
    ./mvnw spring-boot:run
    ```

Приложение будет доступно по адресу `http://localhost:8081`.

## API Endpoints

### 1. Сокращение URL

**`POST /api/v1/shorten`**

Сокращает длинный URL и возвращает сгенерированный или пользовательский псевдоним.

*   **Request Body (JSON):**
    ```json
    {
      "originalUrl": "http://very-long-and-complex-url.com/some/path/to/resource?param=value",
      "alias": "mycustomalias",
      "expiresAt": "2025-12-31T23:59:59Z"
    }
    ```
    *   `originalUrl`: (Обязательно) Оригинальный URL для сокращения.
    *   `alias`: (Необязательно) Желаемый пользовательский псевдоним. Если не указан, будет сгенерирован автоматически.
    *   `expiresAt`: (Необязательно) Дата и время истечения срока действия ссылки в формате ISO 8601 (например, `2025-12-31T23:59:59Z`). Если не указан, ссылка будет бессрочной.

*   **Response (Status 201 Created):**
    Возвращает сгенерированный или пользовательский псевдоним.
    ```
    mycustomalias
    ```

*   **Примеры ошибок:**
    *   `400 Bad Request`: Некорректный URL, невалидный формат alias или expiresAt в прошлом.
    *   `409 Conflict`: Псевдоним уже существует.

### 2. Перенаправление по короткой ссылке

**`GET /{alias}`**

Перенаправляет пользователя с короткой ссылки на оригинальный URL.

*   **Path Variable:**
    *   `alias`: (Обязательно) Короткий псевдоним ссылки.

*   **Response (Status 302 Found):**
    Перенаправление на оригинальный URL.

*   **Примеры ошибок:**
    *   `404 Not Found`: Псевдоним не найден или срок действия ссылки истек.

## Запуск тестов

Для запуска всех юнит- и интеграционных тестов:

```bash
./mvnw test
```

Интеграционные тесты используют Testcontainers для запуска временного экземпляра PostgreSQL, поэтому Docker должен быть запущен.
